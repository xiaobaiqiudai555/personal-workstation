# 个人工作站 App · 技术方案

> 版本 v0.2 ｜ 形态：PWA 手机应用（可"添加到主屏幕"，断网可用）｜ 数据：纯本地

---

## 1. 产品定位

一个**装在自己手机上的私人工作站**，把每天绕不开的七件事收进一个入口：

| 模块 | 一句话定位 |
| --- | --- |
| 背单词 | 带间隔复习的每日单词任务，支持拍照识别课本单词导入 |
| 健身 | 只记今天练了什么：部位、器械、重量、次数、时长 |
| 今日提醒 | 每天重复的习惯提醒（喝水、拉伸、复盘） |
| 工作提醒 | 带截止时间的一次性待办，逾期标红 |
| 随手小记 | 一秒记下一个念头，标签分类、全文搜索 |
| 知识扩展 | 联网随机学新知识（维基百科），离线有内置精选兜底 |
| 周易 | 六十四卦完整经文的摇卦与解卦 |

核心原则：**本地优先、断网可用、数据不出手机**。仅"图片识词"与"随机知识"两个增强功能会在联网时请求公共服务（图片仅在设备内识别，不上传；请求不含个人数据），其余全部本机完成。

## 2. 技术选型与理由

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 形态 | **PWA**（HTML + CSS + 原生 JS） | 手机浏览器"添加到主屏幕"即全屏 App 体验；无需应用商店、签名和上架审核 |
| 框架 | **无框架单页应用**（原生 JS + 自研路由） | 零构建、零依赖，双击/部署即用；本鱼一个人维护，框架反而是负担 |
| 数据 | **localStorage**（JSON 分模块存储） | 体量小（见 §6），读写同步简单；未来不够再平滑迁到 IndexedDB |
| 离线 | **Service Worker** 缓存应用外壳 | 断网也能打开；数据本来就在本地 |
| 图片识别 | **Tesseract.js** 本地 OCR（首次约 2MB 英文语言包，随后离线缓存） | 拍照提取英文单词，图片不出本机 |
| 随机知识 | **中文维基百科 REST 随机条目接口**（CORS 直连，无需 Key） | 联网随机学新知识，离线自动降级内置卡 |
| 释义补全 | **dictionaryapi.dev** 免费词典接口（可选联网） | 导入词自动补释义，无网时留"待补释义" |
| 构建 | 无（纯静态） | 任何静态托管（GitHub Pages / Netlify / 自建）都能跑 |

**为什么不选原生 APK / React Native**：
- 原生包需要 Android 构建链和签名流程，改动一次就要重新打包发安装包；
- PWA 改一行刷新即生效，迭代成本几乎为零；
- 体验上用"独立窗口 + 全屏 + 本地数据"已满足个人使用，差异仅在于系统级后台推送（见 §10 风险）。

### 文件结构（规划）

```
personal-workstation/
├── index.html                 # 唯一入口
├── manifest.webmanifest      # PWA 清单
├── sw.js                     # 离线缓存
├── icons/                    # 192 / 512 / maskable 图标
├── css/app.css               # 全部样式（移动端优先、安全区适配）
├── lib/
│   └── ocr/                  # Tesseract.js worker + 英文语言包（本地识别）
├── js/
│   ├── app.js                # 路由、导航、初始化
│   ├── db.js                 # 存储层（schema 版本、读写、备份）
│   ├── utils.js              # 日期、Toast、弹层、防抖
│   ├── modules/              # 七个模块各一个文件
│   │   ├── home.js  vocab.js  fitness.js  reminders.js
│   │   ├── notes.js  knowledge.js  zhouyi.js
│   └── data/                 # 内置静态内容
│       ├── vocab-data.js     # 内置词库（350+ 常用词，支持拍照/粘贴导入）
│       ├── knowledge-data.js # 内置精选卡（离线兜底，约 60 张）
│       └── zhouyi-data.js    # 六十四卦：卦辞 + 爻辞全文
└── README.md                 # 安装与部署说明
```

### 渲染方式

- 单页 + hash 路由（`#/home`、`#/vocab`…），底部 5 个 Tab：首页 / 单词 / 健身 / 提醒 / 更多；
- 每次切页按模块 `render()` 重新渲染内容区，模块内部用事件委托，状态只存数据层；
- 所有写操作立即落盘（localStorage），无需手动保存。

## 4. 七大模块详细设计

### 4.1 背单词（间隔复习）

- **出词**：每日新词配额（默认 20）+ 到期复习词，混合出题；先"回忆自评"再揭晓。
- **自评三档**：不认识 / 模糊 / 认识 → 简化 SM-2 间隔（1 → 2 → 4 → 7 → 15 → 30 → 60 天），"不认识"打回重来。
- **交互**：卡片正面英文 + 音标 + 例句，点自评翻面显示释义与词根提示；键盘/滑动切换。
- **统计**：今日完成 x/y、连续打卡天数、明日待复习数。
- **词库**：内置 CET4/CET6 高频词 350+ 起步，支持粘贴/JSON 导入自定义词表。
- **拍照导入**：课本、单词表拍照或从相册选图 → 本机 OCR（Tesseract.js）提取英文单词 → 去重后勾选确认 → 导入学习队列；有网时自动调词典补释义（无网标记"待补释义，可编辑"）；图片只在设备内处理，不上传。

### 4.2 健身（今日训练记录）

只回答一个问题：**今天练了什么、用了什么器械、做了多重、练了多久**。

- **自动计时**：进入训练页自动开始计时，可暂停；保存时记录当日训练总时长；
- **部位多选**：胸 / 肩 / 手臂 / 背 / 腿 / 有氧，一键勾选本次训练覆盖的部位；
- **器械多选**：杠铃 / 哑铃 / 龙门架 / 跑步机 / 徒手 / 自行车，记录此次用到的器械；
- **动作记录**：每行一次记录"动作名 + 重量(kg) × 次数 × 组数"，随时增删改；
- **汇总**：本周训练天数、累计时长、七日柱状图自动计算；不做长期计划表，轻量为主。

### 4.3 今日提醒（每日重复）

- 每条 = 时间 + 内容 + 重复日（每天 / 工作日 / 自定义）+ 开关；
- 应用打开/前台时每 30 秒扫描一次，到点顶部弹出提醒条 + 底部角标；
- 顶部"今日待办"聚合视图，勾选即完成当天实例（次日自动重置）。

### 4.4 工作提醒（一次性待办）

- 字段：标题、备注、截止时间、优先级（高/中/低）、完成状态；
- 列表按截止时间排序，逾期红色标注并置顶；支持一键完成、编辑、删除；
- 首页显示"今日待办 3/5"汇总卡。

### 4.5 随手小记（速记）

- 全局悬浮 "+" 按钮：任何页面一秒新建；标题可空，正文自动保存；
- 组织：标签（自定义颜色）、置顶、搜索（标题+正文+标签）；
- 自动保存时间戳；空笔记自动清除；支持导出为 Markdown 文本。

### 4.6 知识扩展（联网随机学习）

- **随机学习**：请求中文维基百科"随机条目摘要"接口，展示标题 + 摘要 + 来源链接，"换一条新知识"即随机刷新；
- **隐私**：请求仅随机条目 ID，不发送任何个人数据；凭据不落盘；
- **离线兜底**：断网或接口超时自动切换到内置精选卡（约 60 张，含每日固定卡）；
- **内置精选**：分类浏览（科学 / 历史 / 语言 / 心理 / 效率 / 文化），每张 80~150 字，结构 = 标题 + 正文 + 分类 + 来源备注。

### 4.7 周易（摇卦解卦）

- **起卦**：三枚铜钱六次（模拟），由下往上得到六爻；老阳/老阴为动爻；自动生成**本卦 + 变卦**；也可"手动选卦"直接查。
- **解卦**：展示本卦卦辞、动爻爻辞、变卦卦辞，附简短白话提示（规则性说明，不编排吉凶结论）。
- **内容**：内置《周易》通行本**六十四卦卦辞与爻辞全文**（公版文本，含乾坤用九用六），不依赖联网。
- **历史**：每次起卦自动记录时间、问题、本卦、动爻、变卦，可回看。

## 5. 数据模型（localStorage）

| 键 | 内容 |
| --- | --- |
| `ws.meta` | 版本号、首次使用时间 |
| `ws.vocab` | `{ words:[{w,p,m,deck,ef,interval,due,reps,lapses,src}], settings:{daily}, stats:{days}, imported:[{count,time}] }` |
| `ws.fitness` | `{ logs:[{date,parts:[],equipment:[],items:[{name,weight,reps,sets}],duration,note}] }` |
| `ws.reminders` | `{ daily:[{id,time,text,days,enabled}], work:[{id,title,note,due,priority,done}] }` |
| `ws.notes` | `[{id,title,body,tags,pinned,created,updated}]` |
| `ws.knowledge` | `{ read:[cardId], history:[wikiPageId] }`（内置卡内容在静态数据文件里） |
| `ws.zhouyi` | `{ records:[{id,time,question,hex,moving,changed}] }` |
| `ws.settings` | `{ theme, dailyTarget, notify, name }` |

- 读写统一走 `db.js`：`get(key, default)` / `set(key, value)` / 变更后即时保存；
- **备份**：设置页"导出 JSON / 导入 JSON"，应对换手机、清理浏览器数据；
- 迁移：`ws.meta.version` 升级时按版本补字段，旧数据不丢。

## 6. 提醒机制（重要限制说明）

| 能力 | 实现 | 限制 |
| --- | --- | --- |
| 页面内提醒 | 前台每 30s 扫描 → 顶部提醒条 + Tab 角标 | 仅应用打开时生效 |
| 系统通知（可选开关） | Notification API，需 https + 用户授权 | 页面关闭后不保证送达，无后台推送 |
| 桌面图标角标（可选） | Badging API（支持的浏览器） | 部分 Android Chrome 支持，iOS 不支持 |

**结论**：定位为"打开即提醒"的随身看板，而非闹钟替代品；如需真正后台推送，需要原生壳（后续用 Capacitor 套壳即可复用全部代码）。

## 7. 安装与部署

### 7.1 推荐：免费 HTTPS 托管（手机正式使用）

PWA 的 Service Worker 与"添加到主屏幕"要求 **HTTPS**（或 localhost）。手机通过局域网 `http://192.168.x.x` 访问时浏览器不注册 SW、无法安装，因此正式使用建议：

1. GitHub Pages：新建仓库 → 放入 `personal-workstation/` 内文件 → Settings → Pages → 选分支根目录 → 得到 `https://<用户名>.github.io/<仓库>/`；
2. Netlify / Vercel：拖拽文件夹即部署，自动 HTTPS；
3. 手机浏览器打开链接 → 菜单"添加到主屏幕" → 桌面出现全屏图标。

### 7.2 本机/局域网调试

```powershell
# 电脑本机预览（localhost 属安全上下文，SW 可用）
python -m http.server 8765 -d personal-workstation
# 手机连同一 WiFi，访问 http://<电脑IP>:8765 预览界面（SW/安装不可用）
```

### 7.3 图标与清单

- `manifest.webmanifest`：名称"个人工作站"、独立窗口、主题色、启动图；
- 图标：192/512 常规 + maskable 512（安全区留白），由 Python/Pillow 生成；
- **OCR 语言包**：首次拍照识别需下载英文语言包（约 2MB），之后由 SW 离线缓存，无需再联网；
- **联网功能**：随机知识 / 词典补释义仅在 HTTPS 站点可用（统一走 7.1 部署），无网自动降级。

## 8. 实现路径与验收

| 阶段 | 内容 | 验收标准 |
| --- | --- | --- |
| **M1 骨架** | 单页路由 + 底部导航 + 数据层 + 设置页 | 五页可切换、刷新数据不丢、导入导出可用 |
| **M2 核心模块** | 单词（SM-2）、健身（今日训练记录+自动计时）、提醒（今日+工作+前台弹窗）、小记 | 每个模块增删改查闭环，提醒到点能弹 |
| **M3 内容与增强** | 单词拍照导入（OCR + 词典补释义）、词库 350+、内置知识卡、六十四卦全文 + 摇卦/变卦/历史 | 拍照能识别出词并导入，断网可出题、可解卦 |
| **M4 联网与 PWA** | 随机知识（维基百科 + 离线降级）、manifest + SW 离线 + 图标 + 安装引导 + 深色模式 | 断网可打开、可加到主屏，联网随机知识可刷新 |

预计工作量：M1 半天 → M2 一天半 → M3 一天半 → M4 半天（本鱼手速）。

## 9. 预期效果

- **打开体验**：从桌面图标进入直接是"今日概览"——今天剩几件事、单词差几个、健身练没练、一条新知识，一屏看完；
- **拍照导入**：一页课本拍张照，几秒变成单词队列，省下一个个手打的功夫；
- **健身极简**：进页面点几下——部位、器械、重量、时长，30 秒记完今天的训练；
- **联网涨知识**：每天随机刷到一条真·新知识（维基百科随机条目），来源可点开原文核对；
- **断网可用**：地铁、飞机上照样背单词、记灵感、摇卦，随机知识自动切回内置精选；
- **数据私有**：内容只存在本机浏览器，无账号、无服务器；联网请求不含个人数据；
- **性能**：纯静态资源，首屏 < 1 秒；交互全部本地，无加载等待；
- **换机迁移**：设置页导出 JSON → 新机导入，数据完整还原。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 后台无推送 | 关页面后提醒不响 | 产品定位为随身看板；后续可套 Capacitor 原生壳 |
| iOS 存储可能被清 | 数据丢失 | 设置页一键导出备份；定期提醒导出 |
| 词库体量有限 | 不够背 | 内置 350+ 起步 + 拍照/粘贴导入；后续扩充到 CET4 全量 |
| OCR 识别准确率 | 模糊照片识别错词 | 导入前逐个勾选确认、单词可编辑；保留手动粘贴导入兜底 |
| 联网随机知识不稳定 | 接口超时 / 无网 | 自动降级内置精选并明确提示"离线"；接口失败不阻塞 |
| 词典补释义失败 | 生词无释义 | 标记"待补释义"可手动编辑；内置词库命中优先，不重复请求 |
| 周易文本准确性 | 解读出错 | 采用公版通行本，逐卦校对；解卦只给经文与规则提示 |
| 局域网 HTTP 无法安装 | 手机装不上 | 正式使用一律部署到 HTTPS（GitHub Pages 等） |
