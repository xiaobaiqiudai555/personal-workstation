# 个人工作站（PWA）

一个装在自己手机上的私人工作站：背单词（含拍照识词）、健身今日记录、今日/工作提醒、随手小记、联网+内置知识扩展、周易摇卦解卦。

**纯本地数据 · 断网可用 · 无后端服务器。**

## 功能清单

- **背单词**：SM-2 间隔复习、每日目标可调、连续打卡；拍照/选图 OCR 识词导入、粘贴导入、自动补释义
- **健身**：只记今天练了什么——部位、器械、重量×次数×组数、时长计时
- **提醒**：今日提醒（每日重复）+ 工作提醒（截止时间、优先级、逾期标红），打开时到点弹窗
- **随手小记**：标签、全文搜索、置顶、一键速记
- **知识扩展**：联网随机学（中文维基百科）+ 内置精选卡（断网兜底）
- **周易**：六十四卦卦辞爻辞全文、三枚铜钱起卦、本卦+变卦+动爻解卦、起卦记录

> **联网说明**：仅「随机知识」「词典补释义」「首次 OCR 引擎加载」需要网络，其余全部离线。图片识别在本机完成，图片不上传。

## 本地预览（电脑）

```powershell
python -m http.server 8765 -d personal-workstation
```

浏览器打开 http://127.0.0.1:8765/

> 注意：手机通过局域网 `http://192.168.x.x` 打开时不能"安装"、Service Worker 不生效（浏览器安全限制），只用于看界面。

## 部署到手机（一次性，之后无服务器）

1. 把 `personal-workstation/` 里的全部文件上传到 GitHub 仓库（需 public）；
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)` → Save；
3. 等约 1 分钟，得到地址 `https://<用户名>.github.io/<仓库名>/`；
4. 手机 Chrome 打开该地址 → 右上角 ⋮ → 「添加到主屏幕」；
5. 之后从桌面图标打开，**断网也能用**，数据全部存在手机本地。

## 更新流程

改完文件重新上传 → 手机联网打开一次应用 → 新版本自动缓存；本地数据不受影响。

## 数据备份

应用内「设置 → 导出备份」得到 JSON 文件；换手机时「导入备份」即可完整迁移。
